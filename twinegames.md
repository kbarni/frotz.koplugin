# Twine games compatibility list

**Twine** games support in *Frotz plugin* is still experimental. Twine games are made to be played in a web browser, with full HTML and JavaScript support, which KOReader doesn't have. Our engine runs on the QuickJS JavaScript library and reimplements the Twine story formats (Twine 1, Harlowe, SugarCube, Chapbook, Snowman) without a browser.

Some games include their own JavaScript code or other advanced features that the engine doesn't support. These games may show error messages (undefined variables, unreadable code blocks), hide links, or simply get stuck. Some other games are only available online (mostly on itch.io), so they can't be downloaded and played with the plugin.

The list contains the 70 most rated Twine games on IFDB. 59 of them could be downloaded and tested: 45 of those (76%) are playable (Gold or Silver).

**Legend:**
- **Gold** - Everything works
- **Silver** - The game is playable, but may show some error messages or reach a few dead ends.
- **Broken** - You will get errors or get stuck. Avoid playing these games.
- **Not downloadable** - Available only online

**Note:** The games were tested by AI agents, which played the games using a custom environment for the Twine engine. Playing all these games manually - exploring every branch - would be humanly impossible. Thus some aspects couldn't be tested - for example whether the simplified interface can display all the important elements of a complex webpage.

*Don't hesitate to propose modifications for the list if you encounter problems with a specific game.*
